播报服务 / Narration service

读取状态 / Checking status…

停止会立即中断播报并清空待播事件，不影响 CLI 任务。重新启动后从下一个任务回合继续。
Stop interrupts narration and clears queued events. CLI tasks continue. Start resumes on the next task turn.

中文提供 174 个基础说话人及三种机械配置；英文提供 109 个基础说话人。机械朗读保持各自原生中心音高，低音/高音仅调整 ±10%，减少大幅改调的粗糙感。性别未标注，请以试听选择。
174 Chinese and 109 English speakers. Flat delivery keeps each voice’s native central pitch; low/high profiles shift it by only ±10%. Gender is unspecified; choose by preview.

拖动即时保存，无需重启。语速从下一句生效；音量和静音即时影响当前播放。
Changes save as you move the slider. Rate applies to the next utterance; volume and mute apply during playback.

基础语速用于正常播放；积压时逐句加速，队列消退后恢复。提示音保持原速。试听使用基础语速；想试听上限，可暂时将基础语速设为上限后试听。
Speech speeds up as the queue grows and returns to the base rate as it drains. Chimes keep their original speed. To preview the limit, temporarily set the base rate to that value.

勾选时，所选音色是新会话的首选；被占用时自动分配其他音色。现有会话保持自己的音色。取消勾选后所有会话使用所选音色。
Selected voices are preferred for new sessions. Existing sessions keep their assigned voices.

人声以各自原生中心音高进行本地平直处理，减少语调起伏，保持机械朗读。试听与正式播放效果一致。此处理也会削弱中文声调，不能保证消除所有情绪感知。等待和心跳提示不播放人声。
Local constant-pitch processing gives mechanical delivery. Preview matches playback. Chinese tonal clarity may decrease; all perceived emotion cannot be guaranteed absent. Waiting reminders are silent.

提示音 / Chimes

本地音效：完成与提问使用两种不同的叮咚。Local sounds, two distinct chimes.

正在加载音色 / Loading voices…

试听和正式播报均在本机合成，无需网络；首次使用请运行 sound-of-vibe tts install 下载模型。关闭页面不会停止播报；托盘模式请用图标菜单管理服务。
Voice previews and narration run locally. Run sound-of-vibe tts install once to download the model. Closing this page keeps narration running; use the tray menu to manage the service.
